# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 洗印件使用台账

每个片段登记「安全上限」与「已放映场次」，剩余场次 = 上限 − 已映 − 预订占用：

- **预订放映**：一笔预订为清单内每个片段占用 1 场；任一片段剩余不足则整笔挡下，并点名剩余不够的短片。
- **取消预订**：释放占用，不计入已映。
- **放映完成**：实际放映后确认，占用转为已映场次。
- **替换片段**（卡片上的 ⇄）：新洗印件顶替原位置，未放映的预订转给新片段；已映记录留在原片段并进入「替换留档」。
- 列表标签、剩余场次条、核对提醒、顶栏统计与导出清单一律按剩余场次显示。
- 已映与预订分别持久化，重开页面不会混算；旧版数据首次打开时自动补齐台账字段。
