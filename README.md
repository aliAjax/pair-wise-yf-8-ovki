# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移，
并为每个胶片洗印件登记放映使用台账，生成试映前破损与场次余量提醒。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。所有数据保存在浏览器
localStorage 中，刷新或重开页面不会丢失。

## 使用台账规则

每个片段登记三个互相独立的数字：

- **安全上限（limit）**：该洗印件最多可放映的场次
- **已映（used）**：实际已经完成的放映场次
- **已订（reserved）**：已被预订占用、但尚未放映的场次

**剩余可放场次 = 安全上限 − 已映 − 已订**。

- 录入片段时设置安全上限；新片段已映、已订均为 0。
- **预订**：输入场次数点「预订占用」，先从剩余次数中预占；超过剩余次数会被挡住，
  提示短片编号、当前余量和差口，且不会改动任何数据。
- **取消预订**：释放对应占用，不影响已完成记录。
- **完成放映**：把已预订的场次转为「已映」（需先有预订，未预订的场次不能登记完成）。
- **替换片段**：通过「换」按钮登记新洗印件。旧片段尚未使用的预订全部转给新片段；
  已完成场次保留在旧片段上，进入「已替换片段 · 历史台账」（可单独删除）。
  新片段安全上限必须能承接待转入的预订，否则拒绝替换。
- 列表卡片、右侧「试映前核对」提醒、顶部统计和导出清单，一律按**剩余次数**显示；
  剩余为 0 时红色告警且无法再预订，剩余 1–3 场时黄色提醒。
- 导出为文本清单，含每片的上限/已映/已订/剩余，末尾附历史台账。
